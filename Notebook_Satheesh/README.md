This directory contains analysis notebooks for the red-backed vole hippocampal methylation project that I am working on.

Each directory has a README.md file that contains the details of the analysis.

|Notebook|Description|
|---|---|
|01_Data|Download the genome for the red-backed vole (*Clethrionomys rutilus*). Getting basic stats of gff3 file. |
|02_Results|Strand-aware annotation of DMLs and DMRs with genomic feature classification.|
|03_Phase_Signatures|Analysis of phase-specific methylation signatures across Peak, Decline, and Low population phases.|
